# browser-recording-basic 规格

## Goal

让用户可以在网页中录制麦克风音频，停止后生成音频文件，并复用现有上传接口创建 recording。

## User Story

用户打开首页后，不需要准备本地音频文件，可以点击“开始录音”。浏览器请求麦克风权限，用户允许后开始录音。录音过程中可以暂停、继续，停止后系统自动上传录音文件。上传成功后，录音出现在现有列表中，并可继续播放、转写和生成 AI 总结。

## Requirements

1. 页面必须新增“浏览器录音”区域。
2. 用户可以点击“开始录音”。
3. 开始录音前必须检查浏览器是否支持 `MediaRecorder`。
4. 不支持时显示：“当前浏览器不支持网页录音，请换用 Chrome / Edge。”
5. 点击开始后浏览器请求麦克风权限。
6. 用户拒绝权限或获取麦克风失败时显示：“无法访问麦克风，请检查浏览器权限。”
7. 权限允许后开始录音。
8. 页面显示录音状态：未开始、请求权限中、录音中、已暂停、停止中、上传中、上传完成、失败。
9. 页面显示录音时长。
10. 录音中可以暂停。
11. 暂停后可以继续。
12. 用户可以停止录音。
13. 停止后生成音频 Blob。
14. Blob 包装成 File，文件名格式为 `browser-recording-YYYYMMDD-HHmmss.webm`。
15. 前端复用现有上传接口上传该 File。
16. 上传成功后刷新现有录音列表。
17. 新录音可使用现有播放器播放。
18. 新录音可继续使用现有阿里云 ASR 转写和 AI 总结。
19. 停止录音后必须清理 MediaStream tracks。
20. 必须防止重复点击导致多个 recorder 同时运行。
21. 本阶段不做分段上传、自动 ASR、自动总结或真正实时流式 ASR。

## Frontend Interaction

状态流：

```text
未开始 -> 请求权限中 -> 录音中 -> 已暂停 -> 录音中 -> 停止中 -> 上传中 -> 上传完成
```

失败时进入：

```text
失败
```

界面元素：

- 区域标题：“浏览器录音”。
- 状态文本。
- 录音时长。
- “开始录音”按钮。
- “暂停”按钮。
- “继续”按钮。
- “停止并上传”按钮。
- 错误提示区域。

按钮可用性：

- 未开始/上传完成/失败：允许开始录音。
- 请求权限中/停止中/上传中：禁用录音控制，避免重复操作。
- 录音中：允许暂停和停止。
- 已暂停：允许继续和停止。

## API Reuse Design

不新增后端录音 API。

录音结束后前端构造：

```ts
const file = new File([blob], "browser-recording-YYYYMMDD-HHmmss.webm", {
  type: "audio/webm"
});
```

然后复用：

```http
POST /api/recordings/upload
```

上传成功后调用现有录音列表加载逻辑。

## Data Model Impact

不新增数据库表和字段。

录音文件保存后仍写入现有 `recordings` 表：

- `filename`
- `original_filename`
- `file_path`
- `mime_type`
- `size_bytes`
- `duration`
- `status`
- `created_at`

后端允许的上传格式补充：

- `.webm`
- `audio/webm`

## Acceptance Criteria

1. 原有音频上传与播放功能仍然可用。
2. 原有阿里云 ASR 转写仍然可用。
3. 原有 AI 总结仍然可用。
4. 页面出现“浏览器录音”区域。
5. 点击“开始录音”会请求麦克风权限。
6. 允许权限后可以开始录音。
7. 录音时页面显示“录音中”和录音时长。
8. 可以暂停录音。
9. 可以继续录音。
10. 点击停止后可以生成音频文件。
11. 停止后自动上传生成的音频文件。
12. 上传成功后，录音列表出现新录音。
13. 新录音可以播放。
14. 新录音可以继续执行真实 ASR 转写。
15. 新录音可以继续生成 AI 总结。
16. 用户拒绝麦克风权限时，页面显示清晰错误。
17. 浏览器不支持 MediaRecorder 时，页面显示清晰错误。
18. 停止录音后麦克风被释放。
19. 前端 build/lint 通过。
20. 后端测试通过。
21. OpenSpec tasks.md 已更新。

## Out of Scope

- 每 3-5 分钟自动切片。
- 长录音 session。
- 自动 ASR + 自动总结。
- 真正实时流式 ASR。
- WebSocket。
- 系统声音录制。
- 游戏内语音捕获。
- 麦克风 + 系统声音混录。
- 桌面端。
- 虚拟声卡。
- 说话人分离。
- UI 大重设计。
- 登录系统。
- 权限系统。

## Risks / Trade-offs

- `MediaRecorder` 输出格式依赖浏览器，MVP 优先使用 `audio/webm`。
- Safari 支持差异较大，因此不支持时提示用户换用 Chrome / Edge。
- 本阶段停止后才上传，录音过程中刷新页面会丢失当前录音。
- 本阶段只采集麦克风，不解决系统声音或游戏语音采集。
