这是使用 [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app) 初始化的 [Next.js](https://nextjs.org) 前端项目。

## 本地启动

先启动开发服务器：

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

然后用浏览器打开 [http://localhost:3000](http://localhost:3000) 查看页面。

可以从修改 `app/page.tsx` 开始开发页面。保存后页面会自动更新。
